# Allo Health - Reservation System

## Problem Understanding

This project implements a reservation-based inventory system for multi-warehouse commerce.

The main challenge is preventing overselling during concurrent checkout flows while maintaining accurate stock visibility.

Key features:
- Reservation lifecycle
- Concurrency-safe stock allocation
- Reservation expiry
- Idempotent APIs
- Real-time inventory updates
